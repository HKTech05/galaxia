Embed Instruction

To add this chatbot to the real galaxiaresorts.com, simply paste the following script tag just before the closing </body> tag on every page:


<!-- Galaxia Chat Widget -->
<script 
  src="https://your-chatbot-server.com/widget/galaxia-chat.js" 
  data-backend-url="https://your-chatbot-server.com">
</script>

Look at the bottom right corner of this screen to test the actual widget!

Features of this Widget

  • Fully Standalone: Injects its own scoped CSS to prevent layout breaks
  • Mobile Friendly: Expands to full screen on devices under 480px
  • No Typing Needed: 100% button-driven menu navigation to avoid AI hallucinations
  • Persistent Backend: Uses your Node.js backend to fetch pricing, details, and images
